Deal editor

The same app, built with five state-management libraries.

  • Valtio — src-valtio/
    Proxies with key subscriptions.
  • MobX — src-mobx/
    Observables with computed values and actions.
  • Effector — src-effector/
    Events, pure reducers and keyed stores.
  • Jotai — src-jotai/
    Field atoms, shared currencies and derived validation.
  • Zustand — src-zustand/
    Immutable actions and explicit field selectors.
